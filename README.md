# infill-proxy

Translates llama.cpp `/infill` requests (used by [llama.vim](https://github.com/ggml-org/llama.vim)) into OpenAI-compatible completion API calls.

This is an experimental project. The primary goal is to compare the effectiveness of using a general model with prompts versus using FIM (Fill-in-the-Middle) for code completion.
